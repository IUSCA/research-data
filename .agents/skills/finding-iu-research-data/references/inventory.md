# IU data resources outside the catalog

This inventory lists data resources that IU holds, licenses, or brokers, and
that the Research Data Catalog did not list when **Observed 2026-11-05**.
Each row was read from the public page it links, on the date given. Use it
with [catalog.md](catalog.md), not instead of it.

The resource's own page is the source of truth for access terms and
contacts. Read it before telling anyone how to get access. Contacts are
office addresses or contact forms. Each names the page it was read on, on
2026-11-06. No IU KB article lists any of them (searched 2026-11-06). Where
a page lists only people, the row says so.

"Who" uses the resource's own words. Where a page states no eligibility,
the row says "Not stated."

No row states an IU data classification. See `classifying-research-data`
before you store or share any of this data.

## Data services and repositories

These offices help find and deposit data rather than hold it.

- IU Libraries Research Data Services, resdata@iu.edu (from the
  [Research Data Services page](https://libraries.indiana.edu/research-data-services), not the IU KB), "available to all IU
  researchers across disciplines." It publishes to IU DataCORE. Observed
  2026-11-05.
- IU Indianapolis University Library Center for Digital Scholarship,
  digschol@iu.edu (from the [Center for Digital Scholarship page](https://library.indianapolis.iu.edu/digitalscholarship), not the IU KB),
  runs the IU Indy DataWorks repository. Observed 2026-11-05.
