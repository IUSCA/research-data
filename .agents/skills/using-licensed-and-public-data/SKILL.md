# Using licensed and public data

Verified 2026-10-04 against Research Data Catalog entries, IU Libraries,
SSRC, OSoMe, and RDC pages. Sources are listed at the end.

A license decides who may use data, where, and for what. Read the license or
the catalog entry before anything else. The license often names a campus and
an eligible role.

## Licensed data by provider

| Provider | What | Who and where |
| --- | --- | --- |
| IU Libraries | Cross-National Time Series, Gallup Analytics, LDC, ProQuest Statistical Insight, Sage Data | IU Bloomington; IU login |
| Kelley School of Business | WRDS, NielsenIQ, three CoreLogic datasets | IU Bloomington; account request or EULA |
| RDC | Web of Science XML | IU Bloomington; RDC request form; Slate Project |
| ICPSR (through SSRC and Libraries) | Social science data archive, members-only content | IU Bloomington and IU Indianapolis |
| HathiTrust | HTRC Analytics over the HathiTrust corpus | All IU affiliates |

The `finding-iu-research-data` catalog snapshot has links to each entry.

ICPSR membership gives IU Bloomington and IU Indianapolis researchers
"Unlimited data downloads, Data depositing, and Discounted tuition and
scholarships for ICPSR's Summer Program." ICPSR is also a place to deposit
data with controlled access. See `sharing-research-data`.

**Required.** Use licensed data only as its license allows. A license is a
contract IU signed. Breaking it can end access for everyone at IU.

**Recommended.** Before relying on a licensed dataset for a grant, confirm
the license covers the full project. Check the campus, the roles, outside
collaborators, and whether derived data can be published.

## Social media data (OSoMe)

The Observatory on Social Media offers archives and tools. Some are public.
Some are for IU affiliates only.

- **Public:** BlueSky and Mastodon archives, the BlueSky Day 1 archive, the
  Botometer Pro API, the Media Bias Fact Check list, IO datasets, and
  publication data on Zenodo.
- **IU affiliates only:** CoVaxxy, Trains, and 2022 Midterm raw data, a
  platform stream archive, and help applying for the Meta Content Library.
- Requests go through the OSoMe data request form.

**External.** OSoMe warns that the BlueSky Day 1 archive "contains personally
identifiable information and is not anonymized. Researchers should seek
review from their institutional review board (IRB)."

**Required.** Social media data scraped or received under platform terms is
**Restricted** by default, per the IU Data Classification Matrix. Data with
participant identifiers is **Critical**. See `classifying-research-data`.

## Restricted federal and confidential data

- **RADaRS**, the Restricted Access Data Remote Server, is run by the SSRC
  with UITS. It is a Windows secure environment in which "A data custodian
  manages all ingress and egress." Use it when a provider requires an
  enclave. Contact ssrc@iu.edu.
- **Indiana Federal Statistical Research Data Center (FSRDC)** gives approved
  projects access to restricted data from federal agencies such as NCHS,
  AHRQ, BEA, NCSES, and IRS SOI.

## Buying data

The RDC FAQ notes that "you are typically not actually purchasing or
obtaining ownership of data." You are licensing it.

1. Check that IU does not already have it. `finding-iu-research-data` lists
   the steps.
2. Work with your unit's financial manager. The usual route is a contract
   request in BUY.IU through IU Purchasing. Rarely, it is IU Libraries or a
   P-Card.
3. The RDC suggests object code 4015 and commodity code SCI3 (Data
   Purchases) or SCI4.
4. Software or platforms bundled with data may need the UITS Software and
   Services Selection Process.

**Required.** Researchers may not sign a data license or DUA for IU. The
Office for Research Administration or Purchasing signs. See
`sharing-research-data`.

The IU Indianapolis University Library will buy or license datasets on
request, but only campus-wide licenses. It will not host Critical data.

**Recommended.** Ask for a campus-wide or IU-wide license when the cost
difference is small. List the purchase in the Research Data Catalog so the
next researcher finds it.
